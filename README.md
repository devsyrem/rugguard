# RugGuard – Token Analysis Extension  

RugGuard is a Chrome extension and on-chain tool that helps users analyze Solana tokens before interacting with them.  
It provides instant insights into token safety, liquidity, and ownership to protect traders from scams and rug pulls.  

---

## 🚀 Features  
- **Live Token Scans**  
  Instantly fetch token metadata, holder distribution, and liquidity info directly from the Solana blockchain.  

- **Red Flag Detection**  
  Alerts users about common rug indicators such as revoked mint authority, low liquidity, or suspicious ownership.  

- **Seamless dev.fun Integration**  
  RugGuard can be linked to any dev.fun coin or app, giving users one-click access to safety checks.  

- **In-Browser Extension**  
  Works as a Chrome extension for quick checks while browsing pump.fun, dev.fun, or any Solana token page.  

---

## ⚙️ How It Works  
1. Install RugGuard as a Chrome extension.  
2. When you visit a token page, RugGuard automatically queries Solana on-chain data.  
3. An analysis panel shows:  
   - Safety score  
   - Liquidity pool status  
   - Mint authority status  
   - Holder distribution  
4. Use this information to make safer trading decisions.  

---

## 🔗 On-Chain Element  
RugGuard pulls **live data from Solana** to ensure all analysis is transparent and verifiable.  
Every safety check relies on on-chain state (e.g., liquidity ownership, token supply, mint authority).  

---

## 📥 Installation (Developer Mode)  
1. Clone or download this repository.  
2. Unzip the folder if necessary.  
3. Open Chrome and go to: chrome://extensions/
4. Enable **Developer mode** (toggle in the top-right).  
5. Click **Load unpacked** and select the unzipped RugGuard folder.  
6. RugGuard will now appear in your list of extensions.
