# RugGuard Chrome Extension

A Chrome extension for detecting risky Solana tokens directly in your browser. This extension integrates with popular Solana blockchain explorers to provide risk analysis for tokens you're examining.

## Features

- **Token Risk Analysis**: Get instant risk scores for Solana tokens
- **Explorer Integration**: Works directly within Solscan, Solana FM, and Solana Explorer
- **Risk Factors**: View detailed risk factors that may indicate a potential rugpull
- **Account Sync**: Connect with your RugGuard account for premium features

## Installation Instructions

1. Download or clone this repository to your local machine
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" by toggling the switch in the top-right corner
4. Click "Load unpacked" and select the `extension` folder from this repository
5. The RugGuard extension icon should now appear in your Chrome toolbar

## Usage

### Basic Token Check
1. Click the RugGuard icon in your toolbar
2. Enter a Solana token address in the search box
3. Click "Check" to see the risk analysis

### Explorer Integration
1. Visit a token page on any supported Solana explorer:
   - Solscan.io
   - Solana.fm
   - Explorer.solana.com
2. The extension will automatically inject risk analysis information into the page

### Premium Features
1. Click the RugGuard icon in your toolbar
2. Click "Login" to connect with your RugGuard account
3. Upgrade to premium for:
   - More detailed risk analysis
   - Custom risk alerts
   - Watchlist functionality
   - Real-time monitoring
